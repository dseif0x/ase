# Usage

## Run Spring Backend 
* In the root directory of the project, run the following command:
```bash
mvn clean install
```

* To run the spring backend run the following command in the backend directory:
```bash
mvn spring-boot:run
```

## Tests

* To run tests in every Module (or go to directory to only run there) run the following command:
```bash
mvn clean test
```
